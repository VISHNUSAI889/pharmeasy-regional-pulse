# PharmEasy Regional Pulse

A pipeline that cleans PharmEasy's monthly order export, computes SQL-verified
region metrics, flags regions that moved, drafts a reviewed narrative and memo,
and shows everything in a local Streamlit dashboard. No API keys, no paid services.

## 1. Install and run (three commands)

Open a terminal **inside the project folder** (all files must be in the same folder), then:

```
pip install -r requirements.txt
python run_pipeline.py
streamlit run app.py
```

`run_pipeline.py` runs these stages in order:

| Stage | File |
|---|---|
| Dataset generation (only if the CSV files are missing) | `generate_dataset.py` |
| Cleaning + schema validation | `clean_data.py` |
| Build SQLite database | `build_db.py` |
| JOIN validation + region/month metrics (SQL) | `queries.py` |
| Flagging + state persistence | `metrics_engine.py` |
| Draft Context-Insight-Implication report | `draft_report.py` |
| Human review gate + audit log | `review_gate.py` |
| Dashboard (separate command) | `app.py` |

It never overwrites existing CSV files unless you run `python run_pipeline.py --regenerate`.
Notes: the dashboard must be started with `streamlit run app.py` in a terminal (not inside a notebook cell);
`regions_master.csv` must have a column named exactly `region`.

## 2. Cover note

**Headline finding:** Guntur's sales rose +122.19% from April to May 2026, by far the largest swing among the 9 active regions.

**The 4 artifacts:**
1. `app.py`: Streamlit dashboard for live data exploration.
2. CII narrative (embedded at the top of the dashboard): what the data means.
3. `memo.md`: the one-page recommendation.
4. `presentation_storyline.md`: how I would defend the finding live.

**Suggested reading order:** dashboard (see the numbers) -> embedded CII narrative (what they mean) -> `memo.md` (what to do) -> `presentation_storyline.md` (how it is defended).

**Assumption to flag upfront (from the Assumptions field in `memo.md`):** Hypothesis, not verified: Guntur's +122.19% reflects a low April base and/or a shift toward larger, higher-value orders rather than a lasting rise in demand; the order data alone cannot separate these.
